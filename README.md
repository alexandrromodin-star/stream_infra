# Stream

Stream — персональное приложение для актёрских проб и коротких сценических дублей.

Пользователь выбирает заранее подготовленный фрагмент фильма, играет одного персонажа перед веб-камерой, а приложение в реальном времени переносит на лицо персонажа внешность и текущую мимику пользователя. Сцена идёт по исходному таймингу. Оригинальная речь выбранного персонажа приглушается по подготовленным таймкодам, микрофон пользователя и остальная сцена формируют итоговый звук. OBS принимает аудио и видео и записывает дубль.

Первая версия (MVP) ориентирована на Windows и бесплатные решения с открытым исходным кодом. Конкретный live-reenactment pipeline и требования к компьютеру будут выбраны по результатам технического прототипа.

## Текущий статус

- Тестовая машина: NVIDIA GTX 1060, 3 ГБ VRAM; простая веб-камера Logitech; OBS установлен.
- Тестовый кандидат: `D:\Stream\scenes\WFWS - small part.mp4`. Длительность, разрешение, FPS и пригодность ещё предстоит проверить.
- В MVP обязательны и внешность пользователя, и его текущая мимика; обычная замена личности без переноса мимики недостаточна.
- Рабочее допущение прототипа: reference лица пользователя снимается с веб-камеры перед дублем, live-видео управляет мимикой, а положение головы и тела остаётся из фильма. Ожидается подтверждение пользователя.
- Сценические исходники и обработанные файлы хранятся отдельно от Git в `D:\Stream\scenes`.

## Структура на диске D

```text
D:\Stream\
├── repo\                     # Git-репозиторий приложения и документации
│   ├── docs\                 # требования, архитектура, инфраструктура, план MVP
│   ├── prototypes\           # временные технические прототипы
│   ├── scripts\              # скрипты настройки и запуска
│   ├── src\                  # исходный код приложения
│   ├── .gitignore
│   └── README.md
├── scenes\                   # исходные и подготовленные медиафайлы сцен
│   └── <scene-name>\         # видео, stems, маски, таймкоды, манифест
├── models\                   # веса моделей; не коммитить в Git
├── cache\                    # кэш и временные кадры; не коммитить в Git
└── envs\                      # локальные окружения; не коммитить в Git
```

Git хранит код, документацию, скрипты и небольшие текстовые манифесты. Большие видео, аудио, модельные веса, временные файлы и записи дублей размещаются отдельно в `D:\Stream` и не входят в историю репозитория.

## Порядок разработки

Сначала проверить выбранную сцену и обязательный перенос мимики в реальном времени. По результатам измерить задержку, FPS и VRAM, затем утвердить архитектуру и необходимые характеристики компьютера. После этого строить вертикальный срез: один сценический шаблон, один дубль, один выход в OBS.
